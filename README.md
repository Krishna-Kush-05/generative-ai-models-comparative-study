# Assignment 02: Comparative Study and Practical Analysis of Generative AI Models

This repository presents a comparative study and practical analysis of four Generative AI models:

- **Autoencoder (AE)** — Image reconstruction and feature compression
- **Variational Autoencoder (VAE)** — Probabilistic latent representation and image generation
- **Deep Convolutional GAN (DCGAN)** — Deep-learning-based image generation
- **Stable Diffusion** — Text-guided image generation using pretrained diffusion models

## Objectives
- Understand the working principles and architectures of different generative models.
- Implement image reconstruction and generation experiments using Google Colab.
- Compare model outputs, quality, limitations, and applications.
- Analyse reconstruction errors, image realism, generated details, and computational requirements.

## Technologies Used
Python · TensorFlow · Keras · Google Colab · Hugging Face Diffusers · Stable Diffusion · Fashion-MNIST

## Project Scope
Includes practical notebooks, experimental results, visual comparisons, screenshots, and documentation. The focus is on understanding and analysing model behaviour rather than training models from scratch.
